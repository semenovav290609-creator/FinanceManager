# 💰 Персональный финансовый менеджер (Finance Manager)

Консольное приложение на языке **C# (.NET)**, предназначенное для удобного учета и анализа личных доходов и расходов. Проект разработан с акцентом на чистую архитектуру, разделение ответственности (Separation of Concerns) и использование современных возможностей платформы .NET.

---

## 🚀 Основные возможности

* 🟩 **Учет транзакций** — добавление операций с указанием названия, суммы, категории и автоматической фиксацией времени.
* 💾 **Персистентность данных** — автоматическое сохранение всех изменений и загрузка истории при старте приложения через JSON-файл.
* 🔍 **Гибкий поиск** — фильтрация совершенных транзакций по конкретной категории (без учета регистра букв).
* 📅 **Анализ по датам** — выборка и просмотр операций за определенный временной период.
* ❌ **Управление списком** — возможность удаления ошибочно введенных транзакций по их названию.
* 🛡️ **Валидация ввода** — безопасный парсинг пользовательских данных через `TryParse`, исключающий падение программы при неверном вводе.

---

## 🛠️ Технологический стек

* **Язык программирования:** C#
* **Платформа:** .NET 8 / .NET 9
* **Архитектурный шаблон:** Объектно-ориентированное программирование (ООП)
* **Формат хранения данных:** JSON (библиотека `System.Text.Json`)
* **Технологии работы с коллекциями:** LINQ (Language Integrated Query)

---

## 📂 Структура проекта

Проект разделен на логические компоненты для упрощения масштабирования:
1. `Transaction` — модель данных, описывающая сущность отдельной финансовой операции.
2. `FinanceManager` — бизнес-логика приложения: управление коллекцией, фильтрация, подсчет баланса и работа с файловой системой.
3. `Program` — точка входа в приложение, отвечающая за интерактивное консольное меню и взаимодействие с пользователем.
